# PraisonAI — Autonomous Self-Improving Agent Workforce

## 核心定位

**PraisonAI** 🦞 是"5 行代码即可部署的自主自改进 AI 劳动力"，主打 self-improving agents + 内置 memory/RAG + 100+ LLM 支持。

## 核心特性

### Agent 能力
- **Research & Intelligence** — 自主研究、规划
- **Planning & Execution** — 任务拆解 + 执行
- **Protocols & Integration** — MCP / 多协议集成
- **Safety & Control** — 工具 allowlist / 沙箱
- **Agent Skills** — 动态技能系统

### 关键卖点
- 5 行代码即可部署
- Built-in memory + RAG
- 支持 100+ LLMs
- 多 agent 协作框架
- Self-improving（基于历史交互自我优化）

### 与 Hermes 的关系
- 可作为 Hermes 的**外部 agent 编排层**
- 内置 skill 系统与 Hermes Skills 互补
- 多 agent 协作能力可补充 Hermes 的单 agent 局限
