# 内容扩充技巧

当章节字数低于目标（2800字/章）时，按以下优先级扩展。

## 七种扩充技巧

### 1. 内心独白扩展

增加主角面对两难选择时的内心博弈。

**方法**：把一个简单的决策拆成三层：
- 表层：做出决定
- 中层：为什么不能做另一个选择
- 深层：这个决定暴露了他什么样的恐惧/渴望

> 改前：他选择了战斗。
> 改后：他想跑。腿已经在往后退了。但他没有退。不是因为勇敢，是因为他想起来还有人在后面。如果他跑，他们会死在他前面。他不能让这种事发生。腿停住了。

### 2. 背景揭秘扩展

增加角色背景故事，但要**切断而非叙述**——用碎片闪现而非完整回忆。

**方法**：用触感触发，而非主动回忆。

> 改前：他想起三年前师父对他说的话。
> 改后：那句话卡在喉咙里。三年了。他以为自己早忘了。三年前的那个晚上，师父的声音，柴火燃烧的声音，空气里松脂的味道——他猛地回到现实。不行。不能再想这些。

### 3. 战斗/动作场景扩展

补充未尝试过的招式描述，但要**用具体感官**而非招式名。

**方法**：
- 招式名之外，加感受（"震得虎口发麻"）
- 加环境细节（"尘土扬起，迷了眼"）
- 加时间感（"零点几秒，够了"）

### 4. 角色分析扩展

增加其他角色对主角的评价/观察。

**方法**：让一个配角用一句话暴露主角的某个特质。

> 老周看着他，说："你变了。"没解释变了什么。但那个眼神里有一点东西——不是恐惧。是担忧。

### 5. 场景氛围扩展

用感官细节丰富场景。

**方法**：
- 视觉：光线、颜色、距离
- 听觉：声音的距离感（远/近/回响）
- 嗅觉：具体气味而非"难闻"
- 触觉：温度、质地

### 6. 对话博弈扩展

让对话更有张力——每句对话背后都有潜台词。

**方法**：
- 不要正面回答（"你来了。" "是啊。"）
- 用动作/沉默替代对话
- 让角色说A但暗示B

### 7. 结局场景扩展

补充主角的反思和下章预告，但**用触感而非陈述**。

> 改前：这一夜他没睡好。他知道明天会更难。
> 改后：他在床边坐了很久。窗外的光一点点变亮。他没有关窗。冷风进来，吹得他没有那么困了。不，不是这个原因。是因为他不想闭上眼睛。一闭上眼睛，那些画面就会回来。

---

## 扩充禁区

- ❌ 不要为了凑字数增加无意义的打斗
- ❌ 不要添加与当前情节无关的背景信息
- ❌ 不要扩展已经在对话中说清楚的内容
- ❌ 不要用"首先/其次/最后"这种AI标配结构

## 字数自检

使用字数检查脚本：

```bash
python3 - << 'EOF'
import re, sys
path = sys.argv[1] if len(sys.argv) > 1 else "current_chapter.txt"
with open(path) as f:
    text = f.read()
# Remove frontmatter
text = re.sub(r'^---.*?---\s*', '', text, flags=re.DOTALL)
# Remove markdown headings
text = re.sub(r'^#{1,6}\s+', '', text, flags=re.MULTILINE)
chars = len(text)
words = len(re.findall(r'[\u4e00-\u9fff]+', text))
print(f"字符数: {chars}")
print(f"中文字数(估): {words}")
EOF
```
