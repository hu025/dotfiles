## Anti-AI词汇黑名单（项目级）
- Tier1 必换：仿佛、逐渐、众多、面对、竟然、然后、觉得、其实
- Tier2 检查：因为、所以、虽然、但是、首先、其次、最后

## 章节审查清单
1. `progress.json` 章节数与 chapters/ 文件数是否一致
2. `wc -c` 或 Python `len(content)` 验证字数（3000-5000字 ≈ 6000-15000字节）
3. 检查文件内标题行（`# 第X章：`）是否与文件名匹配
4. 检查 UTF-8 BOM 残留（首行 `\ufeff`）
5. 更新 ERRORS.md / STORY_BIBLE.md / CHARACTERS.md / PLOT_POINTS.md / progress.json

## ⚠️ 重要注意事项
- 上下文压缩摘要（compaction summary）可能包含预写章节内容，但实际文件可能不存在
- 任何"章节已写完"的信息都需先用 `ls chapters/` 验证文件真实存在
- 长期连载项目容易积累腐坏：命名不一致、BOM残留、进度落后、设定文档空白
- 每次接手/审查项目时，执行 skill 中"第七步：项目健康检查"
