# 连贯性保证机制

## 角色一致性

- [ ] 角色说话方式一致？（每章抽查一句）
- [ ] 角色面对压力的反应一致？
- [ ] 角色的能力边界一致？（不超纲）

## 情节一致性

- [ ] 本章开头衔接上一章结尾？（读上一章最后3段）
- [ ] 时间线是否自洽？（白天/夜晚/季节）
- [ ] 地理/空间位置是否自洽？

## 设定一致性

- [ ] 能力使用条件/代价每次都一致
- [ ] 角色关系/情感状态和之前章节一致

## 节奏一致性

- [ ] 高潮密度合理？（每章至少一个小波折）
- [ ] 没有连续3章全是压抑没有释放
- [ ] 没有连续3章全是爽点没有压抑
