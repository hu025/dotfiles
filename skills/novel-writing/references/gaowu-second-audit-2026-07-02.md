## 新发现问题

### P0-C 境界线严重混乱（系统性根因分析）

**现象**：第26-40章林默境界在换血/化境/通玄/凝丹间跳了17次。

**根因**：AI分章创作时，把**配角的境界当成主角**写了进去。
- 陈傲换血境 → 出现在林默相关段落
- 陈霖凝丹境巅峰 → 林默说"凝丹境巅峰"被误读
- 顾天明/钱多多等凝丹境 → 出现在林默叙述中

**可靠锚点**：
- 系统提示音 `【叮，突破至XX境】` — 最可靠
- 主角自言自语/心理突破宣言 — 第二可靠
- 章节首次突破声明 — 第三可靠

**不可靠**：
- 旁白描写主角战斗时的境界（容易被配角数据污染）
- 回忆/对比类"XX比YY高两个境界"（说的是配角）

**修复方向**：第26-40章需要15章逐章核查，每个境界描述必须确认主角本人触发。

# em-dash全书扫描
import os, re
base = "chapters/"
for f in sorted(os.listdir(base)):
    if not f.endswith('.md'): continue
    with open(os.path.join(base, f)) as fh: c = fh.read()
    em = c.count('\u2014') + c.count('\u2013')
    ch = re.search(r'第(\d+)章', f).group(1)
    if em > 0: print(f"第{ch:2d}章: {em:3d}处")

# 境界线追踪（只追踪主角本人）
realms = ['凝血境','换血境','聚气境','化境','通玄境','化神境','凝丹境','元婴境']
for ch in range(1, 66):
    fname = [f for f in os.listdir(base) if f.startswith(f'第{ch}章') and f.endswith('.md')]
    if fname:
        with open(os.path.join(base, fname[0])) as fh:
            paras = fh.read().split('\n\n')
        for p in paras:
            if '林默' in p and any(r in p for r in realms):
                realm = [r for r in realms if r in p][-1]
                print(f"第{ch:2d}章: {realm}")
                break
