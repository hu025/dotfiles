# 对话写作规范

## 核心原则

对话是角色性格的体现，不是信息传递的管道。

## 基本规则

1. **每句台词都要有潜台词** — 角色说A，实际暗示B
2. **用动作和沉默替代对话** — "他没回答。" 比 "他摇了摇头说：不。" 更有效
3. **不要正面回答** — 真实对话很少直接回答问题
4. **口语化** — 人类说话有省略、有重复、有废话

## 禁止

- ❌ "你好，很高兴见到你。" → 太正式
- ❌ "我是来告诉你的……" → 信息传递腔
- ❌ "我认为我们应该……" → 书面语
- ❌ 长篇解释性对话 → 用动作/沉默打断

## 有效对话示例

```
"你来了。" 
他没动。
"我以为你不会来。"
"我也以为。"

"那件事……"
"别说了。"
"我必须——"
"我说了别说了。"他终于转过身。但眼睛没有看她。

"杀了他们。"  
她说完，低下头继续吃东西。像是在说今天天气不错。
```

## 对话中的潜台词设计

| 表面意思 | 潜台词 |
|---------|--------|
| "你变了" | 我不认识现在的你了 / 我害怕你 |
| "我没关系" | 我很有关系 / 不要问了 |
| "她走了" | 我失去她了 / 这是我的错 |

## 说话方式体现性格

- **犹豫型**：话断断续续，用省略号多，"可能……也许……我不知道"
- **强势型**：短句、命令式、不解释
- **掩饰型**：转移话题、反问、假装没听到
- **压抑型**：停顿长，声音低，句子短
