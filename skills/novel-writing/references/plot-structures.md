# 情节结构模板

## 三幕结构

### 第一幕：建置（0-25%）
- 建立世界观和日常生活
- 引入主角及其核心问题
- 打破平衡的事件发生

### 第二幕：对抗（25-75%）
- 主角尝试解决问题
- 遭遇挫折和失败
- 中点转折：主角被迫改变策略

### 第三幕：解决（75-100%）
- 最终对决/决定性选择
- 核心问题解决（部分或全部）
- 章末钩子：为下一章埋下新问题

## 爽文节奏模板

### 核心爽点周期（3-5章一轮）

1. **压制**（1章）：主角被压制、被轻视、被打脸
2. **觉醒**（0.5章）：意外发现/突破/转机
3. **碾压**（1-2章）：主角展示实力，爽感释放
4. **余韵**（0.5-1章）：收获、地位提升、新的威胁出现

### 升级节奏

- 小胜利：每3-5章一次
- 中胜利：每10-15章一次
- 大胜利：每30章一次

## 章节情节模板

### 压制章节
1. 开篇：对手出现/轻视主角
2. 发展：主角尝试应对，但力量悬殊
3. 高潮：主角被打压到极限
4. 结尾：意外转机或伏笔

### 觉醒章节
1. 开篇：处于绝境或触发事件
2. 发展：主角发现新能力/领悟
3. 高潮：能力首次展示
4. 结尾：但新问题出现

### 碾压章节
1. 开篇：力量对比已改变
2. 发展：逐一击败对手（但要写细节，不是简单说"轻松获胜"）
3. 高潮：击败主要对手
4. 结尾：收获/地位提升
