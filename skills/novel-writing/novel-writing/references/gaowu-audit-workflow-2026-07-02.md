## AI痕迹修复策略速查

| 类型 | 修复方式 |
|------|---------|
| em dash | 替换为中文逗号 `，` |
| 句首「然后」 | 直接删（句意完整时）或改为直接陈述 |
| AI高频词「再次」 | 删或改为"又一次"/"又" |
| AI高频词「最后」 | 改整个句式结构（"最终"/删整个分句） |
| AI高频词「随着」 | 改为"跟着"/"顺着" |
| AI高频词「不断」 | 删 |
| AI高频词「戛然而止」 | 改为"声音断了"/"就此断了" |
| 枚举型Tricolon | 改动态动作/"四道光芒同时爆发" |
| 对话中「然后」 | 改为"之后"/合并短句（不要硬删） |
