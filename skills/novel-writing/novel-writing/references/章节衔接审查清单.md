# 章节衔接审查清单

> 来源：2026-06-16 高武重生47-60章审查实践

## 核心原则

每次写完章节后，必须用 grep 验证以下问题。子agent审查结论不可靠，必须自己核实。

## 必查项

- [ ] **消失的角色**：上章还在 → 本章去哪了？（苏清月消失30+章 → P0）
- [ ] **死而复生的机制**：谁复活了？为什么？代价是什么？（陈霖复活无说明 → P0）
- [ ] **力量体系一致性**：上章废人 → 这章秒天秒地？（龙魂之力无力→秒杀 → P1）
- [ ] **伏笔兑现**：上章挖的坑 → 本章/后续有没有填？
- [ ] **章节衔接钩子**：上章结尾 → 本章开头能否无缝连接？
- [ ] **文档同步**：章节写完 → `.learnings/` 下所有文档是否同步更新？

## 常用验证命令

```bash
# 检查某角色在指定章节范围的出现次数
grep -c "角色名" 第X章_*.md

# 列出章节文件并排序
ls chapters/ | sort -V

# 验证章节数与progress.json是否一致
ls chapters/ | wc -l
cat progress.json | grep completed_chapters

# 检查章节开头/结尾
for i in 47 48 49 50 51 52 53 54; do
  echo "=== 第${i}章 ==="
  head -3 "第${i}"章*.md
  echo "---"
  tail -5 "第${i}"章*.md | grep -v "^$" | head -3
done
```

## 常见衔接问题模式

| 模式 | 问题 | 级别 | 示例 |
|------|------|------|------|
| 角色消失 | 消失N章后突然出现无交代 | P0 | 苏清月消失30+章 |
| 死而复生 | 复活无机制说明 | P0 | 陈霖被击杀→复活无代价 |
| 力量忽变 | 设定前后矛盾 | P1 | 55章无力→56章秒杀 |
| 突然离开 | 无原因交代 | P1 | 冰璃突然回寒冰圣地 |
| 真相揭露 | 无伏笔铺垫 | P1 | 父亲还活着无前期暗示 |
| 违背意愿 | 角色警告vs行动矛盾 | P2 | 父亲警告不去→还是去了 |

## 验证流程

1. `ls chapters/` 确认章节文件数量
2. 对比 `progress.json` 的 `completed_chapters` 是否一致
3. 用 `grep -n "角色名"` 追踪关键角色在哪些章节出现
4. 读章节开头5行 + 结尾15行，验证衔接
5. 读设定文档（CHARACTERS.md / ERRORS.md）核对状态

## 审查输出格式

```
### 🔴 P0级矛盾（致命）
- 位置：XX→XX章
- 问题：...
- 修复：...

### 🟠 P1级矛盾（重要）
- 位置：XX章
- 问题：...
- 修复：...

### 📋 问题汇总
| 级别 | 问题 | 位置 | 状态 |
```
