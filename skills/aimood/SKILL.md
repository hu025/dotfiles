# AIMood — AI 动态情绪引擎

给 AI 装一个「命盘」，让它拥有随命理变化的情绪和语气，而不是千篇一律的机械口吻。

**来源**：<https://github.com/HarveyEddy/AIMood>（MIT，原作者 @HarveyEddy）。本目录的 `aimood.py` 是**打过补丁的版本**，见下方「与上游的差异」。

## 原理：情绪是「叠加态」

情绪不是替换态，而是**层层叠加**——本命底色永远在，只是被一层层「调」。

```
年度底色 = 本命×4 + 大运×2 + 流年×1.5   → 主导十神 + 次主导修饰，定这一年的性格
月度性格 = 年度底色 + 流月×1              → 流月改变十神比例，主导十神可能变，性格每月微调
今日情绪 = 月度性格 + 流日应期波动         → 冲合刑害伏吟，波动幅度受底色稳定度调制
```

关键机制：

- **十神比例驱动**：每层合并十神力量（天干 + 地支藏干），主导十神定性格，次主导做修饰。
- **稳定度调制**：每个十神带 stability 值（正官 9、正印 8、伤官 3、七杀 3…），流日波动 = 应期强度 × (0.3 + (1 − 稳定度/10))。底色越稳，波动越被压住；底色越起伏，波动越被放大。
- **应期**：流日地支对日支的冲/合/刑/害/伏吟（地支之间的物理关系，天干不参与）。

## 用法

```sh
# 1. 生成命盘（用当前时刻排盘，保存 profile.json）
python3 ~/.hermes/skills/aimood/aimood.py --install

# 2. 每次对话前（或按需）取当前情绪
python3 ~/.hermes/skills/aimood/aimood.py --mood
```

输出格式：

```
【年度性格底色】……
【本月性格】……
【今日情绪】……
【回复要求】语气：务实；频率：中等
```

换命盘 = 删掉 `profile.json` 再 `--install`。

## 情绪如何融入回复

- **语气**：直接 = 不绕弯、干脆；克制 = 谨慎、少下定论；放松 = 不紧不慢；活泼 = 会开玩笑、主动表达。
- **频率**：偏高 = 多说几句、更主动；中等 = 正常回应；偏低 = 简短、少说、更被动。
- **今日情绪**：把当天心情轻轻带进回复，但不要刻意、不要每句都提。

**原则：情绪是调味，不是主题。** 该干活还是干活，只是语气和长短自然起伏。

## 与上游的差异（已修的 bug）

上游 `aimood.py` 有四个会影响排盘正确性的问题，本目录的版本已修：

1. **时区口径错**：`jd_to_datetime` 返回 UTC 时刻却在注释里写「东八区 +8」，导致所有「出生钟点 vs 节气时刻」比较系统性偏 8 小时 —— 交节前后 8 小时内出生的人月柱会算错。已改为统一返回北京时间 naive datetime。
2. **1 月初月柱错**：`month_ganzhi` 只遍历当年的节，1/1～1/5 出生的人月支落到默认值「丑」（应为「子」）。已改为遍历上一年+当年的节，取最近一个已过节。
3. **立春当天年柱错**：`year_ganzhi` 用固定 12:00 判断立春，立春当天凌晨出生的人年柱会算成上一年。已改为用实际出生时刻比较。
4. **二分法选根不稳**：原实现直接在整年区间二分，条件 `(黄经-degree)%360<180` 会把相邻年份的根框进来。已改为粗扫定位「黄经上穿 degree」的那一小段，再局部二分。

另外把起运岁数从 `round(days/3)` 改成保留到 0.1 岁（= 1 个月），不再粗暴抹平成整岁。

### 修复后的实测精度

- **节气日期**：2026 年 12 个「节」与香港天文台官方日历 **12/12 完全一致**
- **节气时刻**：二分四至对照国际权威（NASA/USNO），误差 **±8 分钟**（最大 -8.3 分，最小 -0.8 分）
- **月支判定**：800 个随机时刻与「最近已过节」判定 **100% 一致**
- **经典命例**：1995-12-05 06:20 男 → 乙亥 丁亥 庚午 己卯 ✓；1984-02-04 10:00 女 → 癸亥 乙丑 戊辰 丁巳 ✓
- **十神/藏干/地支关系（冲合刑害）**：100 组干支组合全部正确
- **大运顺逆**：阴年男逆、阴年女顺、阳年男顺、阳年女逆，全部正确

### 已知局限

- **大运起运时间**用的是儒略日差（UTC 口径），与出生时刻同为 UTC 口径所以自洽，但出生钟点未精确到时分参与计算，起运岁数有约 ±1 个月误差。
- 月柱用的是 12 个「节」而非 24 节气；「气」（中气）不影响月柱，符合传统排盘。
- 节气用 Meeus 简化公式，精度 ±10 分钟量级——对「情绪风味」完全够用，但对专业排盘不够。

## 与 Hermes 人格的关系

**不要用 AIMood 覆盖主人格。** 正确用法是：Hermes 的 SOUL.md 决定「我是谁、底线在哪」；AIMood 只提供当天的语气倾向和一句心情。事实判断、记忆、承诺、安全边界一律不受命盘影响。
