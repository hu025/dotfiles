# ETF 横向对比与选品分析

## 核心分析框架

当用户要求"全网分析最便宜的ETF"或"推荐赚钱ETF"时，使用以下框架：

### Step 1: 确定搜索维度

| 用户意图 | 搜索方向 | 重点指标 |
|---------|---------|---------|
| "最便宜的ETF" | 绝对价格最低 | 现价、净值 |
| "最赚钱的ETF" | 涨幅最大 | 近1月/近1年涨幅 |
| "后期能赚钱的" | 机构预判+趋势 | 分析师观点、资金流向、RSI |
| "其他推荐" | 板块轮动+预期差 | 滞涨板块、资金净流入 |

### Step 2: 多维度并行搜索

```
queries = {
    "低价ETF排行": "2026年 ETF 价格排行 最低价 涨幅榜",
    "科技低价ETF": "2026年5月 科技ETF 芯片 半导体 通信 行情",
    "板块轮动": "2026年5月 板块轮动 下一个主线 ETF推荐",
    "机构展望": "2026年下半年 半导体ETF 机构展望 后市预测",
    "风险提示": "2026年5月 科创板风险 芯片板块回调",
}
```

### Step 3: 输出结构

1. **实时数据表** — 代码、价格、涨幅（来自 EastMoney/天天基金网）
2. **机构观点汇总** — 看多/看空并列（避免单一视角）
3. **综合对比表** — 多 ETF 并排，关键指标量化
4. **推荐结论** — 明确、简洁，带风险提示
5. **操作建议** — 止损位、目标位、仓位建议

### Step 4: 本金计算（⚠️ 容易出错）

**只计算当前持仓的本金，已清仓的不计入。**

正确：`512760成本 + 588080成本 + 515050成本 = 当前本金`
错误：`512760成本 + 588080成本 + 已清仓医药ETF成本 = 当前本金`

验证：盈利 = (现价 - 成本) × 股数

## 止损设置原则

- **短线（持有<1月）**：成本价 -10%
- **中线（持有1-6月）**：均线支撑位 或 成本价 -15%
- **动态止损**：持仓期间高点 × 0.95（跌破即出）
- **绝对止损**：任何持仓亏损超过 -20% 必须审视逻辑
