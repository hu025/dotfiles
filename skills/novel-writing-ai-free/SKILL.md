# AI小说去AI化技能

> **AI是工具，不是声音。文字的温度，来自不完美。**

## 核心认知

所有AI检测器测量三个核心统计信号：

| 信号 | AI表现 | 人类表现 |
|------|--------|----------|
| **Perplexity（困惑度）** | 低——AI对每个词"毫不意外" | 高——人类选词有不可预测性 |
| **Burstiness（突发性）** | 均匀——句长高度一致 | 参差——短句穿插长句，节奏起伏 |
| **结构模板** | 固定三段式（引言-正文-结论） | 自然流动，无固定模板 |

> **关键原则**：同义替换不能绕过检测（GPTZero/Copyleaks能检测释义AI内容）。必须改变句子统计结构。

## 一、AI写作特征体系

### 1.1 词汇层面（Tells）

#### GPT-4/ChatGPT特征词
`delve`, `tapestry`, `landscape`, `leverage`, `multifaceted`, `it's important to note`, `undergoes`, `undermines`, `facilitates`, `encompasses`

#### Claude特征词
`certainly`, `I'd be happy to`, `straightforward`, `I should note`, `meticulous`, `comprehensive`, `meticulously`

#### Gemini特征词
`crucial`, `here's a breakdown`, `keep in mind`, `delve deeper`, `holistic`, `game-changer`

#### Llama/Meta特征词
`awesome`, `fantastic`, `hope this helps`, `amazing`, `incredible`, `totally`

#### Mistral特征词
`indeed`, `moreover`, `hence`, `noteworthy`, `furthermore`, `consequently`

#### 中文AI高频词（小说场景）
| 禁用词 | 原因 | 替代表达 |
|--------|------|----------|
| 深入（地） | AI最爱，语义模糊 | 细细/认真/仔细/钻进 |
| 彰显 | 正式书面语 | 体现/显示/说明/让人看见 |
| 不可或缺 | 四字套语 | 必不可少/必须有/缺它不行 |
| 日益 | 公文腔 | 越来越/一天比一天 |
| 显著 | 数据报告腔 | 明显/很大/突出 |
| 逐步 | 机械感 | 一点点/慢慢/渐渐 |
| 持续 | 与"不断"互换无效（两者都禁） | 一直/不停/老是 |
| 不断 | 与"持续"互换无效 | 一直/不停/老是 |
| 极为/极其/相当/颇为 | 程度副词堆砌 | 很/特别/非常/挺 |
| 而言/而言说 | 论述腔 | 说来/来看/按说 |
| 确保 | 命令腔 | 保证/让/使 |
| 旨在 | 目的陈述 | 目的是/是为了/为了 |
| 有助于 | 中立叙述 | 能/可以/帮助 |
| 得以 | 文言书面腔 | 能够/终于/总算 |
| 随着 | 引出背景 | 跟着/顺着/这会儿 |
| 重新 | 重复暗示 | 再/又/第二遍 |
| 再次 | 重复暗示 | 又/再/第二回 |
| 缓缓 | 过度修饰 | 慢慢/一点一点 |
| 突然 | 常被滥用 | 猛地/倏地/一下 |
| 悄然 | 过度诗意 | 悄悄/静默/无声 |

### 1.2 句式层面（Tells）

#### 固定句式（AI最爱，段落开头禁用）
- `在这一刻……`
- `不得不说……`
- `值得注意的是……`
- `从这个角度来看……`
- `正因如此……`
- `正是在这种背景下……`
- `毫无疑问……`
- `从某种意义上说……`

#### 转折句AI模式
- `然而……` → 改为`但……`或直接删
- `尽管如此……` → 改为`可是……`
- `与此同时……` → 改为`这时候……`/`就在这会儿……`
- `与此同时，在另一处……` → 改为具体时间/地点描述

#### 三连排比（Tricolon）—— AI最爱的堆砌
- `A、B、C` 三项枚举在1000字内不超过1次
- 小说不是说明书，禁止`首先/其次/最后`三段式列表
- 连续3个结构相同的短句 = 违规（检测：`他XX，他XX，他XX`）

### 1.3 结构层面（Tells）

| 特征 | AI表现 | 人类修正目标 |
|------|--------|-------------|
| 段落长度 | 高度均匀 | 1句段落 + 6+句段落混搭 |
| 句长 | 趋中（15-25字） | 5字以下短句 + 35字+长句 |
| 开头句式 | 高度一致 | 变化主语位置、句子长度、时态 |
| 连接词密度 | 过高 | 减少过渡词，用动作/感官替代 |
| 情感词汇 | 平均化 | 极端化（非常爱/非常恨，少中间值）|

### 1.4 内容层面（Tells）

- **具体性缺失**：AI写"几天后"，人会写"星期三"
- **感官细节缺失**：无身体触感（手心汗/膝盖发软）
- **立场缺失**：AI倾向中立叙事，人类有偏爱/讨厌
- **不完美缺失**：人类会写错别字、口语、方言
- **口语缺失**：AI对话太正式，人类对话有语气词/停顿

## 二、去AI化技术

### 2.1 词汇替换策略

**安全替换原则**：不要在禁用列表内找同义词替换——改句子结构或意象。

```
❌ 禁用词互相换（无效）
   "持续" → "不断"（两者都禁）
   "深入" → "持续"（两者都禁）

✅ 彻底改写意象
   "持续向外扩张" → "像是封印的边界在慢慢撑开"

✅ 改句子结构
   "深入了解" → "把这件事弄了个清楚"
```

### 2.2 句式变化技术

#### Burstiness提升（核心）
```
# 低Burstiness（AI感）
"他走进房间，看了看窗外，然后坐在椅子上思考了一会儿，最后做出了决定。"

# 高Burstiness（人类感）
"他进了屋。
窗边站了一会儿。
坐下了。
椅子吱呀一声。
决定就这么做了。"
```

#### 插入不可预测词汇
```
# AI：可预测词汇
"他感到非常高兴"

# 人类：不可预测但合理
"他嘴咧到了耳根后面"
```

#### 主语位置变化
```
# AI：主语总在开头
"他推开了门，走进房间。"

# 人类：主语位置变化
"门被他推开了。嘎吱一声。"
"推门。他走了进去。"
```

### 2.3 节奏控制

| 技术 | 效果 |
|------|------|
| 短句断行 | 制造停顿、重量、窒息感 |
| 长句绵延 | 制造时间延展感 |
| 不均匀段落 | 有的一整段，有的一行 |
| 动作打断 | 内心活动被外部动作突然截断 |
| 不完整句 | 话说一半断了，符合人类思维流 |

### 2.4 具体化技术

```
# AI（抽象）
"他感到恐惧"

# 人类（具体+身体）
"他膝盖软了一下"
"手指在发抖，自己都按不住"
"喉咙像被什么东西堵住了"

# AI（模糊时间）
"几天后"

# 人类（具体时间）
"那个星期三"
"第三次核酸之后"
"入秋的头一个早晨"

# AI（中性叙事）
"这本书很不错"

# 人类（立场鲜明）
"这本书好得邪门，让人想骂脏话"
```

### 2.5 不完美植入技术

**适用于需要极强人类感的情景**：
- 偶尔的重复（人类思维回环）
- 轻微的不合语法（口语自然现象）
- 感叹词插入（"说实话""妈的""唉"）
- 方言/口语（视角色背景而定）
- 不规范的断句（`"我——算了"`）
- 轻微的错别字（注意：这是双刃剑，影响可读性）

## 三、人类写作特征强化

### 3.1 身体触感清单（必须有的元素）

- 手心汗 / 指尖凉 / 膝盖发软
- 喉咙紧 / 胸口压 / 胃里翻搅
- 眼窝热 / 鼻子酸 / 后背汗毛竖起
- 脚趾蜷缩 / 牙关咬紧 / 手指节发白

### 3.2 情感极端化

AI写情感趋于平均化（"有些害怕"），人类写极端（"怕得要死"+"同时又兴奋得发抖"）。

| AI表达 | 人类表达 |
|--------|----------|
| 有些紧张 | 紧张到想吐 / 手抖得拿不住杯子 |
| 有点高兴 | 嘴咧了一整天 / 高兴得发疯 |
| 感到悲伤 | 胸口像被什么东西压住，一下一下地疼 |

### 3.3 独特细节

每个场景必须有**只有这里才能用**的细节：
```
# ❌ 通用描写
"他走进房间，很紧张"

# ✅ 独特细节
"他进了屋，第一眼先找窗户。确认了三扇窗都开着，他才把后背靠在门板上"
（紧张到需要确认逃跑路线）
```

### 3.4 未完成思维

人类思维经常不完整就跳转：
```
"他想说对不起，但是——"
"算了。"
"他转身就走。"
```
AI几乎从不在语义未完成处截断。

### 3.5 作者立场

人类叙事有情感偏向，不中性：
```
# AI（中立）
"这场战斗持续了很久"

# 人类（有立场）
"这狗屎仗打了整整一夜"
"打到后来，腿都不是自己的了"
```

## 四、自动化工具

### 4.1 本地AI检测工具

#### lmscan（推荐）
```bash
pip install lmscan
```
- 零依赖，离线运行
- 可识别GPT/Claude/Gemini/Llama/Mistral模型家族
- 提供证据（显示触发词汇）
- 免费开源

#### uncanny
```bash
pip install "uncanny[ml]"
```
- 多方法集成（压缩+困惑度+突发性）
- 句级评分（精确到哪个句子触发了检测）
- CLI友好，支持CI

#### fast-ai-detector
```bash
pip install -e .
fast-ai-detector --text "Your text here"
```
- 基于Gemma 3 4B蒸馏模型
- 支持SAE特征检查
- 对比模式（推荐）

### 4.2 商业检测器（参考基准）

| 工具 | 特点 | 绕过难度 |
|------|------|----------|
| GPTZero | 神经网络分类器 | 中等 |
| Originality.ai | 多模型集成 | 中等 |
| Copyleaks | 句级分析+多模型集成 | 最难 |
| Turnitin | 风格计量学+抄袭库 | 难 |

> **注意**：没有任何检测器100%准确。短文本（<250词）尤其不可靠。已编辑的AI文本更难检测。

### 4.3 AI Humanizer工具

| 工具 | 类型 | 适用场景 |
|------|------|----------|
| WriteHuman | 在线服务 | 快速改造 |
| Grammarly AI Humanizer | 在线服务 | 学术/正式写作 |
| StealthGPT | 在线服务 | 高隐蔽性需求 |
| Walter Writes AI | 在线服务 | 学术/SEO |

> **核心原则**：Humanizer工具处理统计结构，手动编辑添加真实声音。结合两者最有效。

### 4.4 工作流：AI → 人类化

```
1. AI生成初稿
      ↓
2. Humanizer工具结构性改造（破坏统计模板）
      ↓
3. 手动编辑（添加身体触感、独特细节、作者立场）
      ↓
4. 本地检测器扫描（lmscan/uncanny）
      ↓
5. 针对触发句子逐一重写
      ↓
6. 二次检测验证
      ↓
7. 最终人工审核
```

## 五、检测命令速查

```bash
# lmscan - 本地AI检测+模型归属
lmscan scan <file.txt>

# uncanny - 句级评分
uncanny scan <file.txt> --deep

# 检测em dash（AI书面腔标志）
grep -n $'\u2014\|\u2013' <file.txt>

# 检测句首"然后"（AI连接词）
grep -n '^[\s]*然后' <file.txt>

# 检测AI高频词
grep -n '深入\|彰显\|不可或缺\|日益\|显著\|逐步\|持续\|不断\|极为\|确保' <file.txt>

# 检测三连排比
grep -nP '^[^，,\n]{2,30}[、][^，,\n]{2,30}[、][^，,\n]{2,30}[，。]?$' <file.txt>
```

## 六、实战口诀

> **AI写小说三定律**：
> 1. **具体比抽象好**——"星期三早上" > "几天后"
> 2. **身体比心理好**——"膝盖软了" > "他很紧张"
> 3. **不完美比完美好**——断句、重复、立场，比光滑的废话强一百倍

> **去AI化检查清单**：
> - [ ] 有关节发紧/手心出汗/喉咙发紧吗？
> - [ ] 有只有这里才能用的独特细节吗？
> - [ ] 有具体时间/名字/数字吗？
> - [ ] 有作者立场（喜欢/讨厌）吗？
> - [ ] 有口语/感叹词吗？
> - [ ] 有话说一半就断了的地方吗？
> - [ ] 句长变化大吗？（5字~35字+）
> - [ ] 段落长度变化大吗？（1句~6+句）
> - [ ] 禁用词都换掉了吗？
