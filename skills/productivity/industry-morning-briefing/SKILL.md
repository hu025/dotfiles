# 行业早报搜集与编译

定时任务场景：将多个来源的今日行业新闻整合为一份简洁的 Markdown 早报，供用户早晨阅读。

## 典型触发条件

- cron 定时任务（每日早上运行）
- 用户请求"XX 行业早报"
- 每日行业资讯搜集

## 工作流

### 第一步：确定目标来源

中文行业新闻优先使用以下新闻聚合平台（通过 browser 工具访问）：

| 平台 | URL 模式 | 适用场景 |
|------|----------|---------|
| 网易新闻搜索 | `https://www.163.com/search?keyword={关键词}` | 速度快，标题摘要丰富 |
| 百度新闻 | `https://www.baidu.com/s?wd={关键词}+新闻` | 新闻源广 |
| Bing 新闻 | `https://cn.bing.com/search?q={关键词}+新闻+{年份}` | 国际+国内混合 |

> ⚠️ **不要** 使用 `search_files` 工具搜索 URL 路径 — 该工具只适用于本地文件系统，无法访问远程网页。

### 第二步：导航到新闻搜索页

使用 browser_navigate 加载搜索结果页：

```
https://www.163.com/search?keyword=无人机
```

获取搜索结果快照（compact view），提取以下字段：
- **标题**（heading 元素的文本内容）
- **来源**（网易号/来源标注）
- **日期**（标注的时间）
- **链接**（heading 链接的 href）

典型搜索结果元素包含：
- `@e3` 类型的 heading → 标题
- 标题下方相邻的 StaticText → 来源 + 日期
- 图片 link → 可选，用于视觉验证

### 第三步：内容筛选原则

筛选标准（优先级从高到低）：
1. **时效性**：当天或前一天发布的新闻优先
2. **行业相关性**：与目标行业直接相关
3. **重要性**：重大技术突破、政策变化、市场数据优先
4. **多样性**：覆盖不同主题维度（技术、应用、政策、市场）

排除标准：
- 军事冲突/战争相关纯战报（除非与无人机技术直接相关）
- 营销软文/产品广告
- 重复报道同一事件

### 第四步：必要时深入阅读

对重要新闻点击进入详情页，获取更多内容：
- `browser_click(ref)` 进入文章页
- `browser_snapshot(full=true)` 读取正文
- 提取关键事实：具体数据、技术参数、来源机构

### 第五步：编译早报

输出格式模板：

```markdown
📰 **无人机行业早报** [日期]

**【分类】新闻标题**
简要内容描述（1-2 句话），包含具体数据或关键事实。（来源：媒体名，日期）
```

每条资讯控制在 80 字以内，3-5 条为佳，总字数不超过 500 字。

分类标签可选：`【技术突破】`、`【行业应用】`、`【商业动态】`、`【政策法规】`、`【市场数据】`

### 第六步：输出

最终输出只包含资讯内容，不需要其他说明文字。直接以早报格式输出即可。

## 参考：常用搜索关键词

```
# 无人机行业
无人机 | 无人机行业 | 无人机新闻
低空经济 | eVTOL | 植保无人机 | 物流无人机

# 其他行业（替换关键词）
人工智能 | 新能源汽车 | 半导体 | 机器人
```

## 降级方案（browser 不可用时）

**已知：所有终端/curl 方式的降级方案均不可靠。** 在当前环境中测试结果：
- Bing News 中文搜索：返回约 200 字节重定向页（无效）
- Sogou 搜索：返回约 150 字节（无效）
- 百度新闻：返回约 150 字节（无效）
- Google News RSS：返回 0 字节（被屏蔽）
- 中文新闻站 RSS：全部返回 0 字节

如果 browser 工具不可用，建议：
1. 尝试 Ars Technica RSS（`https://feeds.arstechnica.com/arstechnica/index`）获取英文行业新闻
2. 尝试 HackerNews 关键词搜索（`https://hnrss.org/newest?q={关键词}`）
3. 如果以上均不可用，放弃自动化采集，输出 `[SILENT]` 抑制空报。

## 已知陷阱

1. **Bing 中文搜索默认显示"国际版"** — 需要点击切换到"国内版"，否则结果以英文为主
2. **网易新闻有延迟** — 早上运行任务时，当天新闻可能尚未收录，前一天的新闻更全
3. **避免过度深入** — 每条新闻最多点击进入详情页一次，不要逐条深入挖掘
4. **战乱地区新闻过滤** — 俄乌/中东等地区的无人机新闻多为军事战报，与行业技术动态无关时应排除
5. **curl/terminal 直接请求中文新闻站几乎全部失败** — 163.com、百度、Bing、Sogou 均因 JavaScript 渲染或 bot 检测返回空内容或 150-200 字节重定向页。**浏览器工具是唯一可靠方式**，不要尝试用 terminal+curl 作为首选（Google News RSS 同样返回 0 字节）。
6. **中文新闻站 RSS 全部不可用** — 测试过的 RSS 均返回 0 字节（网易、百度新闻、Sogou、Bing News）。英文 RSS 中 Ars Technica 可用，其他大多被屏蔽或不可访问。
