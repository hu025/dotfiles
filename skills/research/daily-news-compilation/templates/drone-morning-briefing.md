# 无人机行业早报 — Output Template

用户指定格式，严格遵循。只输出资讯内容，不加任何说明文字。

```
📰 **无人机行业早报** 2026年07月29日

**【技术突破】标题（核心事实，1-2句）**

**【行业应用】标题（核心事实，1-2句）**

**【市场数据】标题（核心事实，1-2句）**
```

---

## 格式规则

- **总字数不超过500字（中文）** — 每条1-2句话，惜字如金
- **3-5条**资讯，按重要性排序
- 分类标签：**技术突破**、**行业应用**、**政策动态**、**市场数据**、**行业洞察**
- 每条格式：`**【分类】标题**` + 换行 + 1-2句事实（不要加 `来源：` 行）
- 直接从标题行开始输出，**不要任何前缀、说明或结语**
